## 🧠 What It Does

The **TLS Scanner** performs a deep security audit of your server’s SSL/TLS configuration to identify:

- Weak or outdated protocols
- Misconfigurations
- Known SSL/TLS vulnerabilities

It helps ensure your website or application uses **modern, secure encryption standards** and is not exposed to avoidable risks.

---

## 🔍 Key Features

### 🔐 Protocol Versions Supported

The scanner detects which SSL/TLS protocol versions your server allows, including:

- **SSLv2 / SSLv3** – Legacy and insecure (should be disabled)
- **TLS 1.0 / TLS 1.1** – Deprecated
- **TLS 1.2** – Secure and recommended
- **TLS 1.3** – Modern and most secure

---

### 🚨 Vulnerability Detection

The TLS Scanner checks for well-known SSL/TLS vulnerabilities such as:

- **POODLE**  
  Padding Oracle On Downgraded Legacy Encryption
- **Heartbleed**  
  OpenSSL memory disclosure vulnerability
- **BEAST**  
  Browser Exploit Against SSL/TLS
- **CRIME**  
  Compression Ratio Info-leak Made Easy

---

### 📊 Security Grading

- Assigns a clear **A–F security grade**
- Allows quick evaluation of your server’s SSL/TLS security posture

---

## 🚀 How to Use the TLS Scanner

1. Enter the **domain** you want to scan
2. Specify the **port**  
   (typically `443` for HTTPS)
3. Click **Scan Server Security**
4. Review the detailed report, including:
   - Supported protocols
   - Detected vulnerabilities
   - Overall security grade

---

## 📌 Why It Matters

Keeping your SSL/TLS configuration up to date is critical for secure communication.

Weak or outdated protocols (such as SSLv3) can expose sensitive data and leave your server vulnerable to attacks. Regular scans help you:

- Detect and disable weak protocols
- Identify and fix configuration issues early
- Maintain a strong overall security posture
- Meet modern security and compliance standards
