# CSR Generator (RSA & ECC)

A Certificate Signing Request (CSR) is required to issue an SSL/TLS certificate.
This tool allows you to generate both **RSA and ECC CSRs** securely and instantly.

## Supported Key Types

### 🔑 RSA CSR
- Widely supported across all servers
- Recommended key sizes: 2048-bit or 4096-bit
- Commonly used with legacy systems

### 🔐 ECC CSR
- Stronger security with smaller key sizes
- Faster TLS handshakes
- Recommended for modern HTTPS deployments

## What This CSR Generator Does

- Generates private keys securely
- Creates industry-standard CSRs
- Supports both RSA and ECC algorithms
- No local software or OpenSSL required
