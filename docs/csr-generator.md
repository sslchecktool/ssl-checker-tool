## 🧠 What Is a CSR?

A **Certificate Signing Request (CSR)** is a required file when applying for an SSL/TLS certificate.  
It contains your **public key** along with identifying information such as your **domain name, organization, and country**.

The **CSR Generator** makes it easy to create CSRs instantly—without needing OpenSSL, command-line tools, or server access.

---

## 🔑 Supported Key Types

### 🔐 RSA CSR
- Compatible with all major servers and systems
- Recommended key sizes:
  - **2048-bit** (standard)
  - **4096-bit** (higher security)
- Ideal for legacy systems and maximum compatibility

### ⚡ ECC CSR
- Stronger encryption with smaller key sizes
- Faster TLS handshakes and improved performance
- Recommended for modern HTTPS deployments
